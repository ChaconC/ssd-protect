# SSD Protect

A macOS menu bar utility in development for people who keep an external drive
attached. Its goal is to let you protect selected drives from accidental software
ejects and eject them deliberately when you're ready to disconnect.

This repository currently contains the contributor workflow. There is no app
build or download yet. The initial target is macOS 14 or later.

See [Contributing](CONTRIBUTING.md) for local checks and the pull request
workflow. Source is available under the [MIT License](LICENSE).
